1.CSS significa CASCADING STYLE SHEETS ( hojas de estilo en cascada ). 
El CSS es utilizado para diseñar y dar estilo a las paginas webs.
2. Se divide en: 
                .Selector (p)
                .Propiedad (color)
                .Valor(Red)
                .Declaración(color: red;)
                .Llaves( {} ) 
3. <Style>: el CSS se escribe dentro del propio archivo HTML.
   Style.CSS: el CSS se escribe en un archivo separado y se vincula al HTML mediante <link>.
El archivo externo permite reutilizar los mismos estilos en varias páginas HTML y mantener el código más ordenado.
4. El Box Model es el modelo que utiliza CSS para representar cada elemento HTML como una caja.Está formado por: 
     .Content: el contenido del elemnto.
     .Padding: espacio entre el contenido y el borde.
     .Border: borde que rodea al elemento.
     .Margin: espacio exterior que separa el elemento de otros elementos.
5. * : seleccina todos los elementos de la pagina
   p : selecciona todos los elementos <p>
  .MiClase: selecciona todos los elementos que tengan la clase .MiClase.
  #MiID: selecciona el elemento que tenga el id="MiID".

GLOSARIO TECNICO

    Algoritmo

    es una secuencia de instrucciones ordenada y finita diseñada para ejecutar una tarea específica

    Archivo “.bat”:

    es un archivo de texto sin formato que contiene una secuencia de comandos diseñada para ser ejecutado en Windows, permitiendo ejecutar varias operaciones con un clic

    Archivo:

    un archivo es una unidad básica de información compuesta por un conjunto de datos

    Bloque:

    es un información básica o código que se agrupa para facilitar su procesamiento, almacenamiento o ejecución

    Bucle:

    es una secuencia de instrucciones de código que se ejecuta repetidas veces hasta que se cumpla una condición específica y se detenga

    Carpeta:

    una carpeta es un espacio de almacenamiento donde se puede colocar archivos en grupo para organizarlos

    CMD:

    es el intérprete de comandos en Windows. Sirve para interactuar directamente con el sistema a través de comandos

    Comando:

    un comando es una instrucción directa mediante texto que el usuario le da al sistema operativo para que ejecute una acción específica

    Condicional:

    son estructuras de control que permiten a un programa tomar decisiones y ejecutar diferentes bloques de código según si una condición lógica es verdadera o falsa

    Copy:

    copy es un comando de la consola CMD que sirve para copiar uno o varios de una ubicación a otra

    Echo:

    sirve para mostrar mensajes en la pantalla o para activar y desactivar la visualización de comandos mientras se ejecutan scripts o archivos en “.bat”

    Extensión:

    una extensión es un sufijo de 3 o 4 letras al final del nombre de un archivo después de un punto utilizado para indicar su formato

    drive:

    es un servicio en la nube para almacenar, subir, abrir, compartir y editar archivos desde cualquier dispositivo

    Mkdir:

    es un comando utilizado en sistemas operativos como Windows, Linux, Unix, etc para crear una nueva carpeta desde una línea de comandos

    pseint:

    es un software educativo y gratuito para asistir a estudiantes en sus primeros pasos en la programación

    scratch:

    es un lenguaje de programación visual y por bloques que sirve para crear historias interactivas, videojuegos y animaciones.

    scripth:

    es un conjunto de instrucciones escritas en un lenguaje de programación para controlar el funcionamiento de un programa o para automatizar tareas repetitivas

    Trabajo colaborativo:

    es una metodología donde varias personas unen sus habilidades y conocimientos para alcanzar un objetivo común

    Variable:

    es un espacio en la memoria RAM de la computadora diseñado para almacenar datos o valores

    Constante:

    una constante es un valor fijo que no se modifica una vez definido durante la ejecución del programa

    Acumuladores:

    es una variable para sumar valores o realizar cálculos

    HTML:

    es un lenguaje marcado de hipertexto utilizado para estructurar una página web

    CSS:

    es un lenguaje que sirve para personalizar el aspecto visual de una pagina web

    JavaScript:

    es un lenguaje que permite crear animaciones y controlar multimedia dentro de una pagina web

    Etiquetas:

    es una palabra clave o metadato que se usa para clasificar o estructurar informacion.

    Visual Studio Code:

    es un editor de codigo de “codigo abierto”

    IDE:

    es un software utilizado para escribir, compilar, probar y depurar codigo
